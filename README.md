# shaping-view

GTK3-приложение (C11) для наблюдения за иерархией `tc` (traffic control) в реальном
времени: HTB-классы, ingress-шейпинг, связи `mirred → ifb`, скорости, дропы,
оверлимиты, бэклог и 60-секундный график.

Разработано под связку «Linux-роутер + шейперы из `/etc/systemd/scripts`»
(wan0 + brlan0 с двумя ingress-плечами, fastvpn-туннели), но работает с любой
системой, где есть `tc` из iproute2.

## Возможности

- **Дерево интерфейсов** (слева): физическое устройство → `▲ egress` (его HTB-классы)
  и `▼ ingress`-узлы, привязанные через `mirred` к ifb-устройствам.
- **Дискавери ingress → ifb**: разбор `tc -s filter show dev X parent ffff:` —
  каждое `mirred (Egress Redirect to device Y)` становится дочерним узлом `Y`.
  Семантика по матчу: `dst` = адресу хоста → «локальный (на хост)», `u32 0 0`
  → «форвард/весь входящий».
- **ifb скрыты** с верхнего уровня и показываются строго как дочерние узлы.
- **Карточки классов** (справа): classid, имя (из конфига или авто-тег
  «prio N · leaf qdisc»), rate / ceil, прогресс-бар загрузки от ceil,
  счётчики Дропы / Оверлимиты / Бэклог; отступ карточки = глубина HTB × 20 px.
- **График** (снизу): история суммарной скорости выбранного узла, кольцевой
  буфер 60 отсчётов, автошкала 1/2/5.
- **Потоки**: опрос выполняется в рабочем потоке (подпроцессы `tc`/`ip`),
  GUI-поток никогда не блокируется; обновление — через `g_idle_add_full`.
- **Демо-режим**: если `tc` не найден — мок-данные, чтобы интерфейс был живой.

## Сборка и запуск

```sh
pkg-config --exists gtk+-3.0   # требования: GTK+ 3.16+, glib 2.40+
make
./shaping-view
```

`tc` и `ip` ищутся в `PATH` (`g_find_program_in_path`). Чтение состояния tc
работает без root; права нужны только для изменения.

## Имена классов (опционально)

`~/.config/shaping-view/class-names.conf` — формат:

```ini
[wan0]
1:20 = VPN · HTTPS
1:70 = Bulk
```

Секция — устройство, ключ — classid. Пример для конкретной системы:
`doc/class-names.example.conf`. Без файла карточки показывают авто-тег.

## Перевод

Исходный язык интерфейса — русский (строки прямо в коде). Для других языков:
собрать с `make CFLAGS+=" -DENABLE_NLS"`, взять `.po`→`.mo` в
`/usr/share/locale/<lang>/LC_MESSAGES/shaping-view.mo` (домен `shaping-view`).

## Структура кода (shaping-view.c, один файл)

- Модель: `TcIface` / `TcClass` / `TcIngressPath` / `TcQdisc`, `Snapshot`.
- Сборщик: `collect_snapshot()` — `tc -s qdisc show` одним вызовом + per-device
  `class show` / `filter show dev X parent ffff:`; скорости — по дельтам байт
  между опросами (`calc_rate`).
- GUI: `GtkTreeStore`-сайдбар, карточки классов, `GtkDrawingArea`+Cairo график.

## Ограничения

- Детально разбираются HTB-иерархии; прочие qdisc (fq_codel и т.п.) отображаются
  факт присутствия, без деревьев.
- Опрос — поллинг подпроцессов; вариант с libnl/netlink — план на будущее.
